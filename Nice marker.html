Nice <mark>

My take on styling up <mark> element for some nice highlighting

The <mark> element in HTML is pretty cool as it is for highlighting stuff.

But it could be made even cooler.

Here's one in green 🤩

Any colour can be applied easily by updating the --color CSS variable.

A few more colours just for good measure. Nice 💜

🚨 Line wrapping breaks however, please see about to learn more.

About

The default <mark> element is ok, but I thought it could be fun to try something other than the default flat edged yellow highlighter for my upcoming website.

To help me, I used a real highlighter on a piece of paper, and then tried to replicate some of the effects I could see. This approach adds some jaggedness, and a lil extra highlight blob at the end from where you've held the pen for too long 😅

The CSS isn’t the most glamorous, I ended up doing some nudges here and there for the scaling and positioning of the psuedo ::before and ::after I’m using.

Problems

Annoyingly I did run into one right as I was about to share this 😔 Line wrapping breaks! I did try to just drop the contents of the ::before psuedo into the main element, however the SVG filter that comes with it then applied to the text itself 😵‍💫. As a quick patch I'm keeping display: inline-block on it.

You could drop the SVG filter, then it should work? But for me the SVG filter is playing a big roll in getting the aesthetic I was after.

I tried a few things like a wrapping container, background-image, etc, but nothing was working and I don’t have much more energy to give it right now.

Fortunately, for me at least - I can only see myself using this on one or two words at a time; so I don’t see it being an issue. However it should be something you’re aware of should you want to use it yourself. Perhaps you can see an easy fix for it?

(If you do, please share 🥺)
